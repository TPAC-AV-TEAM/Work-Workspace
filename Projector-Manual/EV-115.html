1開機與訊號確認
按下電源鍵後等待暖機完成（約 30 秒）。無訊號時畫面顯示為黑色背景（已設定）。確認訊號來源後，畫面自動切換至輸入畫面。
2測試圖樣（Test Pattern）
遙控器上有專用 [Pattern] 按鍵，可直接進入測試圖樣，無需開啟選單。
主要使用：交叉線影法（全色），用於確認畫面幾何對齊與焦距。其他圖案包含 R/G/B 分色交叉線、彩色條紋（垂直/水平）、伽馬、灰色列、方格圖案、白色、黑色、長寬比畫面。 遙控器：[Pattern] 鍵　或　選單路徑：[設定] → [測試圖樣]
3梯形修正（Keystone）
若畫面出現梯形變形，進入設定選單執行梯形修正。Quick Corner 可對四個角落分別調整，適合非正面投影的場景。 路徑：[設定] → [梯形修正] → [Quick Corner]
4投影方式確認
預設為「前」（桌面正投）。吊裝或背投時，需於擴展選單內切換投影方式，否則畫面將倒置。目前設定值：前/天花板。 路徑：[擴展] → [投影方式] → 前 / 前/天花板 / 後 / 後/天花板
5顯示背景設定
無訊號時的畫面背景，建議設為黑色避免雜色干擾。目前選項：黑 / 應用程式指南。 路徑：[擴展] → [顯示] → [顯示背景] → 黑
6全部重設（注意！）
此操作將清除所有使用者設定，包含梯形修正、色彩、網路等。僅在必要時執行。 路徑：[重設] → [全部重設]
